Usage Guide: How to Customize This Site

A complete manual on how to update your personal information, publications, projects, and styling.

Documentation Guide Help

Welcome to your new academic homepage! This project is designed to be easy to maintain. Here is a guide on how to update everything.

1. Basic Information (Name, Bio, Links)

Open the file src/config.ts.

  • Profile: Update profile object (name, email, role, institution, etc.).
  • Avatar: Put your photo in the public/ folder (e.g., public/avatar.jpg). Update profile.avatar to "/avatar.jpg".
  • Social Links: Update profile.links. Icons supported: github, twitter, scholar, orcid, linkedin, email.
  • Bio: Update the profile.bio field. Supports Markdown (links, lists, bold check).

2. Customize Images & Files

Files referenced by URL should generally be placed in the public/ folder.

  • Avatar: Replace profile.avatar in src/config.ts.
  • Favicon: Replace public/favicon.ico and public/favicon.svg with your own icons.
  • CV / Resume: Place your PDF CV_Lei.pdf in the public/ folder. Update profile.cvUrl in src/config.ts.
  • Browser Tab Title: Is automatically generated from profile.name in src/config.ts.

3. Education History

Open src/config.ts and scroll to the education array.

  • Add or remove objects in the list.
  • Fields: institution, department, degree, startDate, endDate, thesis (optional), supervisor (optional), supervisorUrl (optional).

3. Work & Research Experience

Go to the folder src/content/work/.

  • Each file (e.g., job1.md) represents one entry.
  • The filename doesn’t matter, but using dates helps organization.
  • Frontmatter fields (top of file): company, role, dateStart, dateEnd, location.
  • Body: Write the description in standard Markdown.

4. Publications

This site uses a single BibTeX file for all publications.

  • Open src/publications.bib.
  • Paste your BibTeX entries there.
  • Auto-Bolding: Your name (configured in src/config.ts) is automatically bolded in the author list.
  • PDF & DOI: Add pdf={/path/to/file.pdf} or doi={10.xxx/xxx} to your BibTeX entry to generate buttons automatically.
  • Sorting: Articles are automatically sorted by year (newest first).

5. Projects (This Page)

Go to src/content/projects/.

  • Create a new .mdx file for each project.
  • Required Frontmatter: title, description.
  • Optional Frontmatter: tags, link (external URL), featured (true/false), image.
  • You can write full project details in the file body using Markdown.

6. Styling (Colors)

To change the theme color (the link/highlight color):

  1. Open src/styles/global.css.
  2. Find the :root block.
  3. Change the hex codes for --link-color (normal) and --link-hover-color (hover). 
    :root {
  --link-color: #be8ab7;      /* Change me */
  --link-hover-color: #a2399a; /* Change me */
}

7. Deployment (Step-by-Step for Beginners)

This site is a static website. You can update it and publish it yourself, even if you have no coding background. Here is a step-by-step guide:

7.1. Install Software (First Time Only)

  1. Install Node.js
    • Go to https://nodejs.org/ and download the LTS version for your system (Windows/Mac/Linux).
    • Install it by following the instructions.
  2. Install a Code Editor
    • Recommended: Visual Studio Code

7.2. Download Your Site Code

  • If you received a ZIP file, unzip it to a folder (e.g., Home4Lei).
  • If you use GitHub, you can clone the repository using git clone ... (ask your developer for the link).

7.3. Open the Project

  • Open the folder in Visual Studio Code (or your editor).

7.4. Install Dependencies

  • Open a terminal (in VS Code: Terminal > New Terminal).
  • Run this command (only once after download): 
    npm install

7.5. Preview Locally (Optional)

  • To see your changes before publishing, run: 
    npm run dev
  • Open the link shown in the terminal (usually http://localhost:4321/).

7.6. Build the Site

  • When you are ready to publish, run: 
    npm run build
  • This creates a dist/ folder with your finished website.

7.7. Deploy (Publish Online)

  • Option 1: Vercel (Recommended for Beginners)
    1. Go to https://vercel.com/ and sign up (use GitHub or email).
    2. Click New Project and import your GitHub repo, or drag-and-drop your folder.
    3. Follow the prompts. Vercel will build and host your site for free.
  • Option 2: Netlify
    1. Go to https://netlify.com/ and sign up.
    2. Click Add new site and follow the instructions (GitHub or drag-and-drop dist/).
  • Option 3: GitHub Pages
    1. Push your code to GitHub.
    2. Use GitHub Pages to serve the dist/ folder (see Astro GitHub Pages Guide).

If you get stuck, ask your developer for help or search for “Astro deploy [platform]” online.
