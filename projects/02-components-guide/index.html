Component Usage Guide: Tabs, Steps, and Asides

Your academic website now supports three powerful UI components: Tabs (tabbed content), Steps (step-by-step guides), and Asides (callout boxes). These components help you better organize and present content, making your pages more interactive and user-friendly.

Tabs Component

The Tabs component allows you to organize related content in tabs, where users can click different tabs to view different content.

Basic Usage

import Tabs from '../components/Tabs.astro';

<Tabs tabs={[
  {
    label: "Research Methods",
    content: "Describe your research methods here..."
  },
  {
    label: "Experimental Results",
    content: "<p>Display your experimental data and results...</p>"
  },
  {
    label: "Discussion",
    content: "<p>Analyze results and discuss significance...</p>"
  }
]} />

Markdown Support

The Tabs component now supports Markdown syntax! Just add the isMarkdown: true property:

<Tabs tabs={[
  {
    label: "Methods",
    content: `
      ### Data Collection
      - Project A
      - Project B
      
      ### Analysis
      Used statistical methods...
    `,
    isMarkdown: true
  },
  {
    label: "Results",
    content: "<p>HTML content is still supported</p>"
  }
]} />

Steps Component

The Steps component is perfect for displaying processes, tutorials, or step-by-step instructions. It automatically numbers each step and connects them with visual lines.

Basic Usage

import Steps from '../components/Steps.astro';

<Steps steps={[
  {
    content: "<p>Step 1: Prepare data</p>"
  },
  {
    content: "<p>Step 2: Train model</p>"
  },
  {
    content: "<p>Step 3: Evaluate results</p>"
  }
]} />

Markdown Support

The Steps component also supports Markdown syntax! Just add the isMarkdown: true property:

<Steps steps={[
  {
    content: `
      **Step 1: Literature Review**
      
      Before starting any research project, comprehensive literature review is needed.
      
      - Read the latest papers in the field
      - Understand current research progress
      - Identify research gaps
      
      *Tip: Use Google Scholar, Web of Science, etc.*
    `,
    isMarkdown: true
  },
  {
    content: "<strong>Step 2: Research Design</strong><br/>Based on literature review, design your research methods.",
    isMarkdown: false
  }
]} />

Live Example

  1. Step 1: Literature Review

    Before starting any research project, comprehensive literature review is needed.

    • Read the latest papers in the field
    • Understand current research progress
    • Identify research gaps

    Tip: Use Google Scholar, Web of Science, etc.

  2. Step 2: Research Design
    Based on literature review, design your research methods.
    • Define research questions and hypotheses
    • Choose appropriate methodology
    • Design experimental or data collection schemes
    Important: Ensure methods are reproducible and reliable.

  3. Step 3: Data Collection

    Execute your data collection plan.

    • Conduct experiments or surveys
    • Ensure data quality
    • Record all steps and parameters

    Note: Keep detailed records for peer review.

  4. Step 4: Data Analysis
    Analyze the collected data.
    • Use statistical methods or machine learning algorithms
    • Validate hypotheses
    • Generate visualization results
    Tools: R, Python, MATLAB, etc.

  5. Step 5: Paper Writing

    Write research results into a paper.

    • Follow academic writing standards
    • Clearly express methods and results
    • Discuss significance and limitations

    Finally: Seek peer review and feedback.

Aside Component

The Aside component creates callout boxes for important information, tips, cautions, or additional notes. It helps draw attention to specific content and improves readability.

Basic Usage

import Aside from '../components/Aside.astro';

<Aside>
  This is a basic aside note.
</Aside>

Types and Customization

The Aside component supports different types with distinct styling:

<!-- Note (default) -->
<Aside type="note">
  This is an informational note.
</Aside>

<!-- Tip -->
<Aside type="tip" title="Pro Tip">
  Here's a helpful tip for your research.
</Aside>

<!-- Caution -->
<Aside type="caution" title="Warning">
  Be careful with this approach.
</Aside>

<!-- Danger -->
<Aside type="danger" title="Important">
  Critical information that requires attention.
</Aside>

Markdown Support

The Aside component also supports Markdown syntax! Just add the isMarkdown: true property and provide content via the content prop:

<Aside type="tip" title="Pro Tip" content={`
  **Key Research Tools:**
  
  - Zotero for reference management
  - R/Python for data analysis
  - LaTeX for paper writing
  
  *Remember to backup your data regularly!*
`} isMarkdown={true} />

Best Practices

1. Content Organization

  • Tabs: Suitable for displaying related but different content categories
  • Steps: Suitable for displaying sequential processes or tutorials

2. Content Length

  • Content in each tab or step should be moderate
  • Avoid placing too much content in a single component

3. Accessibility

  • Components support keyboard navigation
  • Use semantic HTML structure

4. Responsive Design

  • Components work well on mobile devices
  • Tabs automatically adjust layout on small screens
